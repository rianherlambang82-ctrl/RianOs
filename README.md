# RianOS 1.0 RC

**RianOS 1.0 RC — Public Testing**

RianOS is a lightweight Linux desktop operating system built to provide a modern, practical desktop experience while remaining suitable for older hardware.

This release is provided as a **Release Candidate (RC)** for public testing and feedback.

## Release Information

- **Version:** RianOS 1.0 RC
- **Status:** Public Testing / Release Candidate
- **Architecture:** amd64 (x86_64)
- **Desktop:** XFCE
- **Base:** Ubuntu 24.04 LTS
- **ISO:** `RianOS-1.0-RC-amd64.iso`
- **ISO size:** approximately 3.8 GB

## Try RianOS Without Installing

RianOS can be started as a Live Session directly from the ISO.

You can test the desktop, applications, hardware compatibility, and installer before deciding whether to install it.

### Live Session Login

The Live Session user is created automatically.

**Username:** `live`

**Password:** `live`

## Installation

To install RianOS permanently:

1. Boot the computer from the RianOS ISO.
2. Start the **Install RianOS** application.
3. Follow the Calamares installer steps.
4. Complete the installation.
5. Reboot and remove the installation media when requested.

> **Warning:** When choosing disk/partition options, make sure the correct target disk is selected. Some installation options can erase existing data.

## Hardware

RianOS is designed with older and lower-resource hardware in mind while still providing a modern desktop experience.

The primary target architecture for this release is:

- 64-bit Intel/AMD processors
- amd64 / x86_64 systems
- UEFI and legacy BIOS systems where supported

Hardware compatibility may vary between systems.
